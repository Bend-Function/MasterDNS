# 云账号删除与本地实例清理

云计算账号页面新增删除入口。输入完整账号名称后，可通过 `DELETE /v1/cloud-accounts/:id` 删除账号及其全部本地实例记录，包括历史清单。账号所有者和管理员可操作；其他用户及不存在的账号返回 404。

删除在同一数据库事务中完成：先获取账号、实例、地址槽位及相关物理租约锁，再清理扫描范围、网卡、地址、授权、健康探测、轮换策略与计划、轮换执行历史、生命周期任务、流量停机策略和闲置 IP 清理批次。地址槽位先于地址删除，避免限制性外键阻止清理。事务失败会回滚全部变更；成功写入不含凭证的 `cloud_account.delete` 审计记录。

关联的云地址发布任务和 DNS Operation 被终止，待执行步骤标记为 skipped。受影响的 Pool 获得一个新的持久调度决策，让共享原发布任务的其他账号继续收敛。Pool 节点解除已删除账号的云关联，并保留已有 IP、健康状态及 DNS 绑定；没有剩余云关联的节点转为静态节点。如果双栈节点仍关联另一个云账号，保留该账号的云关联，并按各地址的来源执行健康检查和 DNS 更新。旧云任务不会因节点转为静态而绕过发布授权。共享 SOCKS 代理配置不随账号删除。

此接口只清理 MasterDNS 数据，不调用云厂商销毁实例或释放资源。实际实例和独立资源仍在云端运行和收费。按远端物理身份保存的限额计数与停机保持状态保留，避免重新导入凭证绕过限额或恢复已停止的自动操作。已有审计和 DNS Operation 历史保留。如果存在已发出但结果未确认的轮换、启停、删除或闲置 IP 释放操作，删除返回 409，保留物理安全锁及恢复记录，需先确认结果或处理未决状态。待执行但尚未发出的任务可随账号清理。

探针租约或结果接收可能与级联删除争用任务和槽位锁。数据库选择删除事务作为死锁或序列化冲突受害者时，整个本地事务最多重试三次；仍有冲突则返回 409，全部数据保持原状。

同步器在建立扫描范围及记录服务级错误时锁定并重新检查账号；账号在读取云端期间被删除时，迟到的清单和错误不会重建本地账号或实例。

验证使用仅监听本机的临时 PostgreSQL 和 Redis，以及测试云适配器，未修改真实云账号、实例或 DNS：

- API 全部测试：362 项通过。
- Web 全部测试：220 项通过，包括名称确认、重复提交防护、失败重试和卸载后的响应丢弃。
- Worker 云同步、生命周期、轮换执行、地址发布及 DNS 取消回归：217 项通过。
- `pnpm build`、API/Web/Worker 类型检查、Web lint 和 `git diff --check` 通过。
- 浏览器预览检查：删除入口可见；输入正确名称前删除按钮禁用，输入后启用；弹窗明确说明本地清理范围。

本次无需数据库迁移。部署时更新 API、Worker 和 Web。
