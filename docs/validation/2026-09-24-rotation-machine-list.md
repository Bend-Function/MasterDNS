# IP 自动轮换机器列表

默认进入“机器与策略”，展示当前用户可见的全部已保存云机器，包括未授权、不支持轮换、未发现地址或账号停用的机器。支持机器名称/IP 搜索及账号、区域、策略状态筛选，每页 20 台。

每个地址族只有一个槽位时可直接开关；多个槽位必须展开后分别操作，没有批量修改。齿轮打开原有策略设置，保留每次故障尝试次数、最小间隔、云端等待及候选复测窗口。未授权不能开启，但可以关闭已经启用的策略；页面不会替用户扩大授权。关闭策略不终止已经开始的轮换。

轮换历史迁至单独标签，原详情、手动启动和确认流程保留。成功启动后重新读取机器槽位状态。列表读取沿用已有接口，限制最多四路并发，不触发云清单同步或额外云 API 扫描；账号或单槽位失败分别提示，不将未知策略显示为关闭。

开关仅在保存成功后更新，保留所有其他已保存参数及策略版本。后台刷新在保存/编辑期间延后并合并；较旧的列表读数不能覆盖刚保存的新版本。失败不自动重发写请求，版本冲突重新读取策略供核对。

本次为 Web 改动，无数据库迁移或新增服务商权限。验证：Web 24 文件、123 项测试通过，TypeScript、lint 和生产构建通过；独立复核已修复刷新竞态、启动后状态刷新和未知策略汇总。浏览器预览验证单台开关、多地址隔离、参数保存回显、IP/账号筛选、历史标签，以及桌面和 390px 手机布局。
