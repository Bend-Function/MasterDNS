# 云 Pool、健康概览与待发布域名验证 — 2026-09-21

## 最终行为

- 健康策略、轮换、云实例、地址选择器、Pool 和域名绑定显示账号、机器名称、IPv4/IPv6 及 IP；当前地址与待验证候选分开标识。实例清单排除历史扫描地址。
- 未发布的域名绑定在 Zone 页可见，可导航到 Pool 或取消。取消与发布串行；已发布或存在结果未确认的 DNS 写入时拒绝直接取消。本地删除、策略版本和审计原子提交。
- Pool 健康按对应地址族及仍启用的域名专属检查统一汇总，外部结果不再覆盖另一类检查的故障。首次云地址待验证不会被当成已确认故障告警；外部策略和最近轮次在 Pool 中可见。
- 历史绿色健康状态必须同时满足当前地址、配置、策略及探测组版本、证据有效期和连续阈值，才显示验证通过。云槽位 API 拒绝纯本地策略。
- Pool 可以直接添加多台云服务器的地址槽位，并为多个域名执行故障转移。节点创建有幂等回执和用户隔离，未经验证的 IP 不直接发布。
- 同 Pool 多槽位发布共用当前持久协调决策，避免相互增加版本导致永久等待。尚未完成的手动 IPv4 发布可参加带版本防护的当前 Pool 决策；旧格式任务、未提升地址、无关 Pool 和已完成手动发布不获得这一资格。
