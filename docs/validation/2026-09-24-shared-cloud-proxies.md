# 可复用 SOCKS 代理

升级时执行常规数据库迁移，应用 `0029_cloud_proxy_profiles.sql`。现有云账号中的 SOCKS URL 在首次读取代理列表时自动迁入该账号所有者名下的独立配置；原有已加密云凭据仍可继续运行。请先完成迁移再从新页面修改代理选择。

「SOCKS 代理」页可创建多个有名称的 `socks5://` 或 `socks5h://` 出口，单独检测草稿或已保存代理的连通性、出口 IP 与延迟。只访问固定 HTTPS ipify 端点，不查询位置；认证信息加密保存、不预填或回显。一个代理可分配给同一所有者的多个云账号。管理员可指定配置所有者，普通用户仅能查看自己的代理。

「云计算账号」页在接入新账号及现有账号的代理选择对话框中提供同一所有者的代理与「直连」。保存选择先通过该路径验证云身份，再原子更新账号关联和加密凭据。编辑已被使用的代理会验证所有关联账号的身份；任何一项不符则整次修改回滚。代理在仍被账号使用时不能删除，须先切换这些账号。云凭据轮换继续保留其代理选择。

代理列表 API 不返回 SOCKS URL 或用户名密码，仅返回名称、已去凭据的端点和关联账号。服务商 API 仍使用现有 SOCKS 传输路径；月流量检查、实例操作和换 IP 均随云账号选择使用该代理。旧的按账号 SOCKS 接口暂保留兼容，修改它会取消共享代理关联；新界面只使用可复用代理接口。
