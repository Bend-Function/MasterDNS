# Manual AWS IPv4 Implementation Plan

**Goal:** One explicit AWS IPv4 change with DNS publication, independent of health configuration.
**Spec:** `docs/superpowers/specs/2026-09-20-manual-ipv4.md`
**Architecture:** Extend durable rotation incidents with manual trigger and nullable health epochs. Reuse existing cloud execution, DNS operations and cleanup. Manual publication authority is server-derived and scoped to the exact incident/version; automatic behavior retains its health checks.
**Tech Stack:** TypeScript, Nest/Fastify, Drizzle/PostgreSQL, Next/React, Vitest.

## Global Constraints

- AWS EC2/Lightsail IPv4 only. Preserve managed and family authorizations.
- Manual trigger changes once, no probes or automatic-policy enablement required, update bound DNS.
- Never manufacture healthy observations. Never repeat uncertain cloud side effects.
- Persist all intents, preserve leases and version fences. No live AWS mutations in tests.
- Only parent commits/pushes; agents edit their assigned files and report tests.
