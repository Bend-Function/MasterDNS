# 云实例生命周期与月流量停机

用户要求增加启动、停止、删除云机器，以及可关闭的月流量阈值停机。支持当前 EC2、Lightsail、Azure VM、Linode 四种服务。只实施和离线验证，不对真实云资源执行操作。

## 产品行为

实例详情页新增启动、停止、删除操作、操作历史和月流量停机策略。启动/停止需要现有 managed + allowStopStart；删除新增 allowDelete，默认 false，并要求输入完整 externalId 确认。自动策略默认关闭；按 UTC 自然月，可以选择 total 或 outgoing，阈值由用户填写（界面 GB，存储安全整数字节）。开启策略需要管理和停机授权，关闭策略始终允许所属用户操作。

用户追加要求：后台默认每小时检查一次，可按实例配置 60–86400 秒（界面 1–1440 分钟）。工作队列有界并发，不依赖页面打开。云指标有发布延迟，因此含义是“首次观测到用量 >= 阈值即申请停机”，不是精确断流或账单硬上限。未知/缺失/错误数据不能当作零或触发停机。检查按当前 UTC 月份且重新确认策略版本，防止跨月或关闭策略后误停。

自动停机后不自动开机；关闭策略也不自动开机。开启策略且当月仍超阈值时，页面启动请求被拒绝，提示先提高阈值或关闭策略；从云控制台重新开机仍会在下一轮检查再次停止。已经停止的实例不会反复发送 stop。Azure stop 使用 deallocate；删除沿用各云厂商资源删除语义，不主动额外删除独立磁盘/IP，界面说明相关数据可能按云配置被删除或继续收费。

## 持久操作

生命周期操作是 PostgreSQL 持久任务（queued/in_flight/succeeded/failed/unknown/cancelled），API 幂等入队、Worker 轮询并观察。先授权、核对远端账号和精确实例身份，再持久标记派发，最后调用单次云写；网络超时/崩溃后只观察，不自动重复不确定写操作。明确拒绝或限流可安全延后重试，保留 Retry-After。操作历史仅暴露脱敏状态和时间。

同一物理实例用现有 physicalKey 与 lease 串行，重复本地账号不能绕过。存在已派发未确认的换 IP 操作时，生命周期操作等待观察结束，不覆盖 unresolvedStep。生命周期任务排队后阻止新的轮换/清理/发布写入；已派发的轮换仍允许观察。停止成功后持久 power hold 阻止健康失败引发自动换址，只有成功启动才清除；删除成功保留本地审计历史并标记实例远端不存在。

删除排队及派发前均检查云槽位/IP Pool 绑定、已知 DNS/地址引用和未结束换址/清理状态；有关联先解除再删除。排队的删除持有地址保护，新建绑定/发布不得竞态引用即将删除的地址。使用数据库锁和现有账号→实例→slot→physical lease 顺序，禁止事务内等待云端。

月流量检查使用持久检查租约，进程重启不会丢失策略。限额触发时保存当月用量、检查时间、错误/停机原因；新的一月不沿用旧月触发证据。取消尚未派发的自动操作须再次校验策略版本；已经发出的云端请求无法撤回。

## 适配器

用户追加要求：云账号支持手动配置 SOCKS 代理，默认直连，支持 socks5/socks5h（优先 socks5h 远端 DNS）。代理 URL/用户名密码保存在已有加密凭证中，不回显，仅显示已配置状态和脱敏端点。账号验证、EC2/Lightsail/STS/CloudWatch、Azure OAuth/ARM、Linode API 均走该账号代理；测试注入传输仍可替换。配置更改先验证同一远端身份再保存，失败不能覆盖旧值；删除代理恢复直连。UI 独立“SOCKS 代理”页面，按云账号配置，不要求重新输入云密钥。手动检测连通性、出口 IP、耗时；用户已明确取消位置显示，不调用地理位置服务。检测仅通过所选代理请求固定 HTTPS IP 查询服务，不携带云凭证。

独立 inspectLifecycle(ref) 获取轻量电源状态与不可变身份，mutateLifecycle(action,snapshot) 再次核对身份后最多执行一次写操作。EC2 InstanceId、Lightsail ARN、Azure vmId、Linode ID/创建信息用于避免同名资源重建误操作。删除后 404 只在相同已验证云账号下解释为 deleted。Azure stopped_allocated 与 deallocated 分开，只有后者满足 stop 完成。

新增 IAM：EC2 StartInstances/StopInstances/TerminateInstances；Lightsail StartInstance/StopInstance/DeleteInstance；Azure VM start/action、deallocate/action、delete；Linode linodes:read_write。沿用账号身份验证和只读流量权限。生命周期操作使用对应厂商已知 API 限额及共享冷却，不能把启停操作误算进静态 IP 小时/日预算。

## 边界与验证

新增表及删除授权默认值用迁移维护。覆盖所有权/重复提交/精确删除确认/绑定保护、停机和轮换互斥、未知写恢复、开关关闭与版本竞态、月界、阈值等号/空数据、已停机幂等、人工启动与仍超额策略。适配器使用真实请求形状的 fake。运行 PostgreSQL/Redis 集成、已有换址与流量回归、编译和前端验收，最后只读独立复核。
